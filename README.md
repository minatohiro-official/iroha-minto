## GitHub公開方法

1. minatohiro-official組織の指定リポジトリに管理権限がある認証で操作し、Ownerが **minatohiro-official** であることを確認します。
2. `minatohiro-official/iroha-minto` が存在しなければPublicリポジトリを作成します。既存ならOwnerと内容を確認し、既存変更を保護して統合します。
3. このフォルダのファイルをmainブランチへコミットします。`.github/workflows/pages.yml` も含めます。
4. Settings → Pages → Build and deployment → Sourceを **GitHub Actions** に設定します。
5. Actionsで `Publish IROHA MINTO to GitHub Pages` を実行します。
6. 成功後、公開URLで全ページ・アセット・メニュー・コピー・見積もりを確認します。

ワークフローは指定リポジトリ以外では実行されません。公開アーティファクトにはHTML・assets・SEO用ファイルだけを含め、READMEや確認書類は含めません。

## 端末プレビュー

制作例のボタンを押すと、公開サイトを390×844（スマホ）、768×1024（iPad縦）、1024×768（iPad横）、1280×800（PC）のiframeで表示します。枠全体は利用者の画面に収まる倍率で表示します。初期表示は保存済みPC画面で、外部サイトはクリック時のみ読み込みます。実機の画面・操作感や端末固有の挙動を保証するものではありません。外部サイト側の埋め込み制限や通信状況により表示できない場合には、通常の公開リンクをご利用ください。外部サイトはsandbox付きiframeで表示します。プレビュー内の機能・情報取り扱いは紹介先サイトのサービスに属します。

検証追記: 2026-10-12、公開ページの両制作例でスマホ390px・iPad縦768px・iPad横1024px・PC1280pxのiframe内viewportと表示を確認。物理端末の検証とは区別しています。CSS/JSを更新する際は各HTMLのasset URLのvパラメータも変更し、以前のブラウザキャッシュが残らないようにしてください。

プレビューの負荷対策: 外部サイトはボタン操作時のみ読み込み、同時に動かすのは1件まで。別の制作例を表示したとき、閉じるボタンを押したとき、タブが非表示になったときにiframeを空に戻して読み込みを停止します。通常表示は軽量WebP画像・遅延読み込み・ローカルCSS/JSのみです。
